Now use it

        
After flashing, unplug the Pico and plug it back in. It now shows up as a security key, not as a drive.

      


      

        

          

            
          

          
Add a passkey

          
Open a site's security settings (GitHub, Google, Microsoft, passkeys.io…), choose Add passkey or Add security key, and pick the USB/external key option. When the LED blinks, press BOOTSEL once.

        

        

          

            
          

          
Sign in

          
At the sign-in prompt, choose the passkey / security key option. The Pico can sign you in without a username. Press BOOTSEL when the LED blinks.

        

        

          

            
          

          
Set a PIN (optional)

          
If your browser offers to set a PIN, do it. Some sites require it, and it protects the key if it is lost. You type the PIN in the browser, not on the Pico.

Good to know

      

      

        

          
          
Re-flashing keeps your passkeys
Firmware and credential storage use separate flash areas. Only a factory Reset erases your passkeys.

        

        

          
          
64 passkeys on the device
It stores up to 64 resident passkeys (for username-less sign-in) plus unlimited non-resident credentials that take no storage.

        

        

          
          
Works with major browsers
Chrome, Edge, Firefox and Safari on Windows, macOS, Linux and Android support FIDO2 security keys. No app is needed after flashing.

        

        

          
          
It is a DIY key
Anyone with physical access can read the flash. Treat it as a learning tool and keep a second login method on every account.

        

      

    


    

      

        
Troubleshooting

        
Most problems come down to the cable, BOOTSEL mode, or a missing USB permission.

      


      

        The Pico does not appear in the browser picker
        

          
Check these in order:

          
1. Use Chrome or Edge on a desktop. Firefox and Safari do not support WebUSB — use the drag-and-drop method instead.

             2. Make sure the Pico really is in BOOTSEL mode: unplug it, hold BOOTSEL, plug it in, and wait for the RPI-RP2 drive.

             3. Try a different USB cable and port. Charge-only cables are a common culprit.

             4. Close other programs that may be using the Pico (another browser tab, picotool, a VM).

          
On Windows, install the WinUSB driver once with Zadig: put the Pico in BOOTSEL mode, open Zadig, choose RP2 Boot (Interface 1), select WinUSB, and click Install Driver. Drag-and-drop works without this driver, so it is always a valid fallback.

        

      


      

        Linux says “Access denied” or the device list is empty
        

          
Your user needs permission for the Pico's USB device. Add a udev rule for the bootloader:

          
echo 'SUBSYSTEMS=="usb", ATTRS{idVendor}=="2e8a", MODE:="0666"' | sudo tee /etc/udev/rules.d/60-rp2040.rules
sudo udevadm control --reload-rules
sudo udevadm trigger

          
For normal passkey use after flashing, also install the project's HID rule:

          
sudo cp udev/70-pico-passkey.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger

          
Then unplug and replug the Pico. The rule file is in the repository.

        

      


      

        The flash failed or stopped halfway
        

          
Nothing is bricked — the RP2040 bootloader is in ROM and always available. Unplug the Pico, hold BOOTSEL, plug it back in, and try again. If the browser flasher keeps failing, use the drag-and-drop method.

        

      


      

        A site does not offer “Add passkey”
        

          
Not every site supports WebAuthn yet. Look for “passkey”, “security key”, “FIDO2” or “two-factor authentication” in the site's security settings. The page must be served over HTTPS (or localhost). Test with passkeys.io to confirm the Pico works.

        

      


      

        The Pico is not recognised after flashing
        

          
Unplug it and plug it back in — the first boot after flashing can take a few seconds. It should enumerate as 2e8a:f1d0. On Linux, check with lsusb and install the HID udev rule above if the browser cannot see it. Make sure you are using a data cable and a powered port.

        

      


      

        How do I reset the key and delete all passkeys?
        

          
Plug the Pico in and, within the first 10 seconds, start a security-key reset from your browser or the site's security settings, then press BOOTSEL to confirm. This wipes the stored credentials. Re-flashing the firmware alone does not erase them.

The GitHub repository has the source, build instructions, FIDO2 capabilities, and the security analysis.
