Your passkey, on a Pico.

Flash a Raspberry Pi Pico into a USB passkey, right here in your browser.

  1. Unplug the Pico. Use a data USB cable, not a charge-only one.
  2. Hold BOOTSEL while you plug it in. When a drive named RPI-RP2 appears, release the button.
  3. Click the button and choose RP2 Boot in the browser picker.

The browser blocks USB access on this page because it has no real origin. Serve the folder over HTTP and open it from http://localhost: python3 -m http.server 8000 --directory docs

Chrome or Edge on desktop. The firmware goes straight to the Pico over USB — nothing is uploaded.

No WebUSB? Download the .uf2 file and drag it onto the RPI-RP2 drive.

Educational hardware with no secure element. Read the security notes.
